## How to Run

### Problem Statement 1: Practical Tasks

First, navigate into the `Problem Statement 1` directory so that relative paths for datasets and SQLite databases resolve cleanly:

```bash
cd "Problem Statement 1"
```

#### Task 1: API Data Retrieval and Storage
Fetches book records from the Open Library REST API, saves them into a local SQLite database (`books.db`), and prints the stored records to the console.
```bash
python Problem_statement_1_A.py
```

---

#### Task 2: Data Processing and Visualization
This task fetches student test score data from an API, calculates the class average, and displays a bar chart comparing individual scores against the average.

1. **Start the Mock API Server (Terminal 1):**
   ```bash
   python mock_scores.py
   ```
   *The server runs locally at `http://127.0.0.1:5000/scores`.*

2. **Run the Data Processing & Visualization Script (Terminal 2):**
   ```bash
   python Problem_statement_1_B.py
   ```
   *This fetches the data, calculates the average score, and renders the Matplotlib bar chart.*

---

#### Task 3: CSV Data Import to SQLite
Reads user data (`name`, `email`) from `users.csv` and inserts the records into a local SQLite database (`users.db`).
```bash
python Problem_statement_1_C.py
```
